# Lab 3: Розробка, документування та агентна верифікація Java-компонента

## 📌 Призначення проєкту
Навчальний проєкт для освоєння практик розробки об'єктно-орієнтованих Java-компонентів (`FunList`, `Cons`, `Empty`), написання модульних тестів за допомогою JUnit, ведення Javadoc-документації та використання AI-асистентів (Gemini CLI) як інженерного інструменту в межах циклу DevOps.

## 🛠 Вимоги до середовища
- **Java Development Kit (JDK)**: версія 21 або новіша
- **Apache Maven**: версія 3.9+
